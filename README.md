## 我为什么做它

生活里，我常常会遇到一些突然袭来的情绪。

有时是一件很小的事，有时只是一个念头。等我察觉的时候，自己已经陷在里面了。我说不清那是什么，也不知道该怎样面对，只觉得心里越来越沉。这样的时刻多了，情绪就容易积压，低落也会停留很久。

我开始想：有没有一种更轻一点的方式，让我在被情绪带走的时候，先认出它？

不是马上解决它，也不是要求自己立刻开心起来。只是能够停一下，对自己说：

> 原来，这个感觉又来了。

情绪宠物，就是从这个想法开始的。

## 给情绪一个名字，再给它一个形象

你可以给一种熟悉的感受取个名字，再选择一个你觉得贴近它的形象。它意味着什么，由你决定，没有标准答案。

下次它出现时，你也许会更容易认出它。轻轻点一下，留下这次相遇；愿意的话，再写几句。不想写，也没有关系。

我希望它能成为一个小小的提醒：你可以感受到情绪，也可以观察它，不必每一次都立刻跟着它走。

这里不需要每天打卡，也不需要把所有感受都解释清楚。

## 背后的心理学设计依据

设计借鉴了**接纳与承诺疗法（Acceptance and Commitment Therapy，ACT）**中的心理灵活性视角：觉察当下经验，对内在感受保持开放，并选择符合自己价值的行动，而不是以消除情绪为唯一目标。[¹](https://contextualscience.org/act)

- **当下觉察与接纳**：注意正在出现的情绪、念头和身体感受，不急着评判或压制。
- **认知去融合（cognitive defusion）**：看见“我正在产生一个念头”，而不自动把它当成事实或必须服从的命令。命名与形象化在这里是一种观察体验的交互隐喻。[²](https://contextualscience.org/about_act)
- **情绪标记（affect labeling）**：用语言辨认感受。相关实验研究发现，标记情绪可能影响主观情绪反应；但研究情境不等于日常使用，更不代表本产品的效果。[³](https://doi.org/10.1037/a0023503)

这些概念是设计依据，**不是本产品的疗效背书**。情绪宠物不是完整的 ACT 干预，尚未经过临床效果验证，也不提供诊断、治疗或危机支持。

## 如果你愿意，来试试看

无需注册，打开网页就可以开始。给感受命名，选择一个形象；当你再次认出它，点一下就记下来了。不想写字，也没有关系。

记录保存在当前浏览器里，不会自动发送给我，也不会跨设备同步。请偶尔在设置里导出备份；清理浏览器数据或更换入口可能让记录无法保留。更新时继续用原网址和原快捷方式，不必重新添加。

如果你觉得某个地方温柔、顺手，或者让你困惑、没有帮助，都欢迎告诉我。你不需要分享私人经历，一句真实的使用感受就很好。
